# Blog Generator

This project generates blogs using the OpenAI API based on user-provided prompts. It includes a frontend UI built with Next.js, and is designed to be deployed on Vercel.

## Features
- User-friendly interface to enter blog prompts
- Utilizes OpenAI API for professional AI-written content
- Deployed on Vercel for easy accessibility

## Development

1. Install dependencies:
   ```sh
   npm install
   ```

2. Run the development server:
   ```sh
   npm run dev
   ```

3. Build for production:
   ```sh
   npm run build
   ```

4. Start the production server:
   ```sh
   npm start
   ```
